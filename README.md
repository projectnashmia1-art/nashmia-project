# Nashmia Operations Hub

NASHMIA INDUSTRIES — DASHBOARD + SIDEBAR

Apple Liquid Glass Premium Enterprise UI

Build the Dashboard frontend only for the Nashmia Industries Container Logistics Platform.

The dashboard must look extremely beautiful, premium, futuristic, elegant and expensive.

The visual inspiration should be:

Apple Liquid Glass + modern macOS + premium enterprise SaaS + luxury logistics command center.

Do NOT create a generic admin dashboard.

The interface should feel like a product designed by a world-class Apple-level product design team.

---

1. CORE VISUAL STYLE

Use a refined Liquid Glass design language.

The glass effect must be:

- translucent

- soft

- layered

- elegant

- subtle

- highly readable

- premium

Avoid excessive transparency.

The interface must never look blurry or cheap.

Use:

- backdrop blur

- translucent surfaces

- soft borders

- subtle highlights

- large rounded corners

- gentle shadows

- layered depth

- smooth micro-interactions

Overall feeling:

Calm + Intelligent + Premium + Operational + Futuristic

24. LIQUID GLASS DETAILS

Use multiple glass layers.

Example:

Main glass:

background: rgba(255,255,255,0.68);

backdrop-filter: blur(28px) saturate(130%);

-webkit-backdrop-filter: blur(28px) saturate(130%);

border: 1px solid rgba(255,255,255,0.75);

Subtle shadow:

box-shadow:

0 10px 40px rgba(0,0,0,0.06),

inset 0 1px 0 rgba(255,255,255,0.8);

Do not overuse shadows.
